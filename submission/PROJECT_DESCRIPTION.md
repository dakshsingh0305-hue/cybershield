# CYBERSHIELD - Cybersecurity Awareness Platform

## Overview
CYBERSHIELD is a Next.js-powered cybersecurity awareness and training platform designed to equip users with the knowledge and tools to identify and mitigate digital threats.

## Key Features
- **URL Scanner**: A client-side, local-only heuristic analyzer that identifies potential phishing and malicious URL patterns without data transmission.
- **Phishing Lab**: Interactive simulations to practice identifying phishing emails and websites.
- **Cyber Academy**: Educational modules on digital hygiene, password security, and social engineering.
- **Dashboard**: Personal progress tracking and skill assessment.

## Technology Stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS
- TypeScript
